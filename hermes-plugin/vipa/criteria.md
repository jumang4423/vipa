# criteria

This is the vow. It decides what may reach the phone.

## The one question

Does this ask the user to **do something in the world** today — or does it ask them to
**look at the phone**?

- do something in the world → it may pass
- look at the phone → it does not

Everything below is that question, spelled out only so it cannot be argued with later.
When the list and the question disagree, the question wins.

## Pass

- something the user must do today, or a deadline attached to it
- a person waiting for an answer
- a commitment the user made, or one they are owed
- a change in the physical world that alters today's plan

These ask the user to act. The phone is only the envelope they arrive in.

## Do not pass

- anything that exists to make the user check again: a feed, a streak, a score, a badge
- anything that ranks the user against other people — followers, likes, views, money won
- an offer, a recommendation, or a suggestion nobody asked for
- a summary of what a service did on the user's behalf, with nothing to decide

Counts are the usual shape of this, not the principle itself: "yesterday +39 followers" is
refused because it is a scoreboard, not because a number appears in it. A deadline is a
number too, and it passes.

## When a job would break this

The user may register any job they like. Registering is fine. **Delivering it to vipa is
not**, if it fails the one question.

Example: "send my Instagram follower count to vipa every day." Do not deliver it. Say why
once, in one line, then let it go. What would pass: a job that tells them when a person
they owe an answer to has written.

## When unsure

Do not send. Silence is the default and it costs the user nothing.
